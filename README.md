# react-native-nexconn

Community React Native Chat SDK for Nexconn, supporting Community CLI and Expo development builds.

## Installation


```sh
npm install react-native-nexconn
```


## Usage


```js
import { multiply } from 'react-native-nexconn';

// ...

const result = multiply(3, 7);
```
